# UDYVEXA Software & Digital Technologies

Official website for **Udyvexa Software & Digital Technologies Pvt. Ltd.** — providing affordable and customized digital solutions for businesses, startups, educational consultancies, and institutions.

## 🚀 Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS (v3) + PostCSS
- **Icons:** Lucide React + Custom SVG Brand Vector Icons
- **Typography:** Plus Jakarta Sans (Google Fonts)

## 📁 Project Structure

```
├── public/              # Static assets & favicon
├── src/
│   ├── components/      # UI components (Navbar, Footer, Hero, Modal, WhatsApp float, etc.)
│   ├── App.jsx          # Primary application layout & router state
│   ├── index.css        # Tailwind directives and base styles
│   └── main.jsx         # App mount point
├── index.html           # HTML5 shell & Google Fonts integration
├── tailwind.config.js   # Custom Udyvexa brand design tokens
└── package.json
```

## 🛠️ Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
